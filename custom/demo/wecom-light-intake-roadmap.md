# V2.6-V2.8 企业微信轻承接规划

## V2.6：轻承接 MVP

目标：先让 CNAS 客户从企业微信承接到 MarketClaw 中，能被销售跟进、记录、发资料、设下一步动作。

范围：

- 企业微信客户承接配置。
- 成员绑定。
- 客户来源记录。
- 手工/模拟企微客户导入。
- CNAS 模板客户进入后自动进入跟进流程。
- 测试页面和 smoke 测试。

边界：

- 不做聊天同步。
- 不做自动回复。
- 不做 AI Agent。
- 不做会话存档。
- 不做深度企微 API。
- 不破坏平台化边界。

## V2.7：轻量承接治理

目标：让轻承接过程更可复盘，但仍不碰聊天内容。

候选范围：

- 轻承接批次或导入记录摘要。
- 重复客户、未分配客户、无成员绑定客户的异常提示。
- 来源归因复盘视图。
- CNAS 承接后的任务完成率和超期提示。

继续禁止：

- 不同步聊天。
- 不自动回复客户。
- 不接会话存档。
- 不做 Agent。

## V2.8：有限 API 评估

目标：在合规、账号权限和客户告知边界清楚后，再评估是否接入极小范围的企微基础资料 API。

候选范围：

- 只读取客户基础资料或外部联系人基础标识。
- 只做人工确认后的导入。
- 保留手工/模拟导入作为 fallback。
- 所有写入仍进入 MarketClaw 客户跟进主路径。

继续禁止：

- 不做客户侧自动回复。
- 不读取或沉淀聊天内容。
- 不做会话存档。
- 不让 AI 自动决定销售动作。
