# V2.2 演示数据准备说明

## 数据原则

演示数据应使用真实但脱敏的线索，数量控制在 20 到 50 条。不要为了展示功能准备过多字段，优先保证销售能看懂客户背景和下一步动作。

## 必备字段

- 客户名称
- 联系人
- 手机或微信备注
- 来源渠道
- 所属业务线
- 当前阶段
- 负责人
- 最近沟通摘要
- 下一次跟进时间
- 客户当前问题

## 推荐字段

- 客户标签
- 风险提示
- 意向等级
- 关注产品或服务
- 已发送资料
- 历史跟进记录

## 演示问题样例

- 这个服务多久能看到效果？
- 费用大概是多少？
- 有没有类似案例？
- 如果做了没效果怎么办？
- 我们现在还没确定预算，可以先了解什么？

## 不准备内容

- 不准备真实客户隐私数据。
- 不准备真实企业微信 Secret。
- 不准备真实 API Key。
- 不准备复杂资料合并样本。
- 不准备自动外发消息场景。
