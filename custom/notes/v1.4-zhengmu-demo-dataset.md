# 版本记录：v1.4-zhengmu-demo-dataset

## 1. 样板数据设计目标

V1.4 的目标不是新增复杂系统能力，而是在 V1.3.2 已稳定的登录、RBAC、多租户隔离、任务、审计和 Playwright 基线上，补一套可直接对外演示和销售使用的整木行业样板企业数据包。

这套数据要满足三个要求：

1. seed 后无需再手工补数据，打开系统就能演示。
2. dashboard、客户详情、销售工作台都能看到真实分布，而不是零散样例。
3. 四类客户路径要清楚，让销售和演示人员知道每一类客户该看什么、怎么讲。

## 2. 四类客户演示路径

### 业主客户

- 典型来源：小红书、抖音、官网、线下活动。
- 重点关心：效果、环保、价格、交付、售后、设计落地。
- 推荐资料：整木定制避坑清单、真实案例图册、交付流程说明、环保与售后说明。
- 推荐任务路径：首次沟通、发送案例图册、了解房屋面积和装修阶段、预约初步方案、报价后跟进、15 天沉默激活。

### 经销商客户

- 典型来源：视频号、公众号、线下活动、转介绍。
- 重点关心：利润、政策、区域保护、总部支持、样板门店、风险。
- 推荐资料：招商手册、产品体系说明、合作政策说明、样板门店案例、到厂考察邀请。
- 推荐任务路径：发送招商资料、了解所在城市和门店情况、招商负责人沟通、邀约到厂考察、政策确认跟进。

### 设计师客户

- 典型来源：朋友圈、小红书、转介绍、活动。
- 重点关心：审美、落地、工艺、材料、案例、项目配合。
- 推荐资料：高定案例图册、工艺节点说明、材料样册、设计师合作机制、项目配合流程。
- 推荐任务路径：发送案例图册、了解设计师项目类型、建立项目合作沟通、发送工艺节点、项目报价配合。

### 工厂客户

- 典型来源：公众号、视频号、官网、转介绍。
- 重点关心：获客、招商、品牌、成交、企业微信、AI 推广、GEO。
- 推荐资料：企业微信承接自查表、整木企业增长诊断表、品牌增信方案、GEO 推广说明、业务增长中台合作建议。
- 推荐任务路径：发送增长诊断表、了解企业获客方式、判断承接问题、安排深度诊断、推动合作沟通。

## 3. 推荐演示账号

- 企业管理员：`boss@zhengmu.local`
  - 适合演示 dashboard、客户列表、客户详情、任务模板管理、审计日志。
- 销售顾问：`sales@zhengmu.local`
  - 适合演示销售工作台、自己负责客户的详情、当前任务和跟进节奏。

## 4. 推荐演示顺序

1. 用企业管理员登录 `/app/zhengmu-demo/dashboard`。
2. 先讲来源分布、客户类型分布、阶段分布和销售跟进概览。
3. 进入客户列表，分别打开业主客户、经销商客户、设计师客户、工厂客户样本。
4. 在详情页讲客户基础信息、推荐资料、推荐话术、推荐下一步动作、已有跟进、当前任务、可选模板。
5. 切换到销售账号，进入 `/app/zhengmu-demo/todos`。
6. 演示今日任务、逾期任务、高优先级任务、本周待跟进、已完成任务以及不同客户类型任务。

## 5. 每个页面该看什么

### dashboard

- 看来源分布是否覆盖抖音、小红书、视频号、公众号、官网、朋友圈、转介绍、线下活动。
- 看客户类型分布是否同时包含四类客户。
- 看阶段分布是否覆盖新线索、已发资料、已联系、已诊断、已报价、待成交、已成交、待激活。
- 看销售跟进概览是否有客户数、待跟进、任务数、已成交等统计。

### 客户列表

- 看不同客户类型、来源、阶段是否都有样本。
- 看负责人分配是否同时覆盖销售、运营、企业管理员。

### 客户详情

- 看客户类型、来源渠道、当前阶段。
- 看推荐资料、推荐欢迎语、3/7/15 天话术、推荐下一步动作。
- 看已有跟进记录和当前任务。
- 看创建任务表单和任务模板是否可直接用于演示。

### 销售工作台

- 看今日任务、逾期任务、高优先级任务、本周待跟进、已完成任务是否都有数据。
- 看任务卡片里能否直接看出不同客户类型。
- 看“我的高意向客户 / 我的报价客户 / 我的待激活客户”是否有真实样本。

## 6. 已知限制

- 当前演示路径仍然不接企业微信 API，提醒队列只做站内模型预留。
- 演示数据虽然更完整，但任务提醒发送、失败重试、企业微信消息分发仍未实现。
- Playwright 仍建议按 spec 单独 reset 数据库和 seed，不建议跨版本并行混跑。

## 7. 下一步建议

1. 如果后续要继续强化演示体验，可以增加一个只读的“演示说明页”，把账号、入口和讲解词直接放到系统里。
2. 可以继续扩充任务模板的按客户类型推荐逻辑，让客户详情页更像销售 SOP。
3. 在不接企业微信 API 的前提下，可先补一个提醒队列后台查询页，增强演示闭环。
