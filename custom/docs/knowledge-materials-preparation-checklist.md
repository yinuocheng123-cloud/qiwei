# 企业资料准备清单

## 1. 企业介绍

- 资料用途：
  帮助系统理解企业定位与背景。
- 最低准备标准：
  一段清晰的企业简介。
- 推荐格式：
  TXT / Markdown / 粘贴文本。
- 投喂后会生成什么：
  企业介绍类候选知识、基础标准回复。
- 谁负责审核：
  TENANT_ADMIN 或 OPERATOR。

## 2. 产品介绍

- 资料用途：
  帮助形成产品/服务介绍口径。
- 最低准备标准：
  核心产品或服务说明。
- 推荐格式：
  TXT / Markdown / CSV。
- 投喂后会生成什么：
  产品介绍、FAQ、标准回复候选。
- 谁负责审核：
  TENANT_ADMIN 或 OPERATOR。

## 3. 服务说明

- 资料用途：
  统一服务内容和交付边界。
- 最低准备标准：
  说明做什么、不做什么。
- 推荐格式：
  TXT / Markdown。
- 投喂后会生成什么：
  服务说明、边界类候选知识。
- 谁负责审核：
  TENANT_ADMIN 或 OPERATOR。

## 4. 百问百答

- 资料用途：
  快速形成 FAQ 基础库。
- 最低准备标准：
  10 条以上真实高频问答。
- 推荐格式：
  `问：/答：`、`Q:/A:`、`问题：/回答：`
- 投喂后会生成什么：
  FAQ 候选知识。
- 谁负责审核：
  TENANT_ADMIN 或 OPERATOR。

## 5. 价格说明

- 资料用途：
  统一价格表达边界。
- 最低准备标准：
  有价格范围、收费方式或报价规则说明。
- 推荐格式：
  TXT / Markdown / CSV。
- 投喂后会生成什么：
  价格边界候选、报价相关 FAQ。
- 谁负责审核：
  TENANT_ADMIN 优先。

## 6. 成功案例

- 资料用途：
  用于支撑说服力和案例类回复。
- 最低准备标准：
  至少 3 个案例摘要。
- 推荐格式：
  TXT / Markdown。
- 投喂后会生成什么：
  案例知识、标准回复候选。
- 谁负责审核：
  TENANT_ADMIN 或 OPERATOR。

## 7. 交付流程

- 资料用途：
  统一交付步骤与周期解释。
- 最低准备标准：
  一份流程概述。
- 推荐格式：
  TXT / Markdown。
- 投喂后会生成什么：
  流程类知识、周期解释候选。
- 谁负责审核：
  TENANT_ADMIN 或 OPERATOR。

## 8. 常见异议

- 资料用途：
  帮助销售处理预算、犹豫、对比等问题。
- 最低准备标准：
  至少 5 条常见异议和建议回应。
- 推荐格式：
  问答文本。
- 投喂后会生成什么：
  异议处理候选知识。
- 谁负责审核：
  OPERATOR 初审，TENANT_ADMIN 把边界。

## 9. 风险边界

- 资料用途：
  约束不能乱承诺的表达。
- 最低准备标准：
  明确列出哪些内容不能承诺。
- 推荐格式：
  文本清单。
- 投喂后会生成什么：
  风险提醒、禁止承诺类候选。
- 谁负责审核：
  TENANT_ADMIN 优先。

## 10. 不建议承诺事项

- 资料用途：
  保护销售和企业口径。
- 最低准备标准：
  有一份“不要说什么”的清单。
- 推荐格式：
  TXT / Markdown。
- 投喂后会生成什么：
  禁止承诺候选知识。
- 谁负责审核：
  TENANT_ADMIN 优先。

## 11. 售后说明

- 资料用途：

- 最低准备标准：
  说明售后支持方式与边界。
- 推荐格式：
  TXT / Markdown。
- 投喂后会生成什么：
  售后 FAQ、边界类知识。
- 谁负责审核：
  TENANT_ADMIN 或 OPERATOR。

  帮助销售在前期沟通中少踩坑。
- 最低准备标准：

- 推荐格式：
  TXT / Markdown。
- 投喂后会生成什么：

- 谁负责审核：
  TENANT_ADMIN 优先。

  TXT / Markdown / CSV。

- 谁负责审核：
  OPERATOR。

## 14. 销售常用话术

- 资料用途：
  把已有一线表达整理进候选池。
- 最低准备标准：

- 推荐格式：

- 投喂后会生成什么：
  标准回复、异议处理、个人话术升级候选。
- 谁负责审核：
  OPERATOR 初审，TENANT_ADMIN 定标准。

## 15. 现有客户标签

- 资料用途：
  帮助更快理解客户分类和常见分层。
- 最低准备标准：
  一份标签说明或导出清单。
- 推荐格式：
  CSV / 文本清单。
- 投喂后会生成什么：
  标签说明类知识和训练补充背景。
- 谁负责审核：
  OPERATOR。
