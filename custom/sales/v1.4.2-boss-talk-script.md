# 客户老板版讲解话术

## 1. 老板现在的问题是什么

很多企业现在不是完全没有客户，而是客户来了以后没有被真正接住。

抖音有人看，小红书有人问，视频号有人加，公众号也有人咨询，但最后这些客户往往散在不同销售的个人微信里。

老板经常会遇到几个现实问题：

1. 知道外面好像有人在问，但不知道客户到底从哪里来；
2. 知道销售加了不少人，但不知道哪些客户还在跟，哪些已经断了；
3. 知道大家都很忙，但看不到客户到底推进到哪一步；
4. 知道有些客户很重要，但没有一眼看出来谁最该马上处理。

说白了，不是没有客户，而是客户来了以后没有被系统化接住。

## 2. 为什么企业微信没有真正用起来

很多企业以为用了企业微信，就是把个人微信换成企业微信。

但如果企业微信里没有下面这些东西：

1. 客户标签；
2. 客户阶段；
3. 跟进任务；
4. 资料推荐；
5. 销售提醒；
6. 老板看板；

那它本质上还是一个聊天工具，只是换了一个账号体系。

真正用起来，不是“有没有企微”，而是“企微背后有没有一套业务增长管理方法”。

## 3. 我们做的是什么

我们不是来接管你们公司，也不碰财务、人事、行政、审批这些系统。

我们只做业务增长这一条线，帮企业把五件事理清楚：

1. 客户从哪里来；
2. 客户来了怎么接；
3. 客户怎么分类；
4. 销售怎么跟；
5. 老板怎么看。

你可以把它理解成：围绕企业微信，把客户增长和销售跟进这条线搭起来。

## 4. 为什么要按客户类型跟进

业主、经销商、设计师、工厂老板，关心的问题完全不一样。

1. 业主要案例和保障；
2. 经销商要政策和利润；
3. 设计师要工艺和落地；
4. 工厂老板要获客和成交。

如果大家都用同一套话术、同一套资料、同一套跟进动作，转化一定会乱。

系统的价值就在这里：

不是把所有客户都堆在一起，而是让不同客户走不同转化路径。

## 5. 做完以后企业得到什么

做完以后，企业至少能把下面这些事情看清楚：

1. 客户来源清楚；
2. 销售跟进清楚；
3. 客户阶段清楚；
4. 资料发送清楚；
5. 重点客户清楚；
6. 逾期客户清楚；
7. 老板看数据清楚。

这不是多了一个系统，而是把原来散着跑的客户增长过程收回到企业自己手里。

## 6. 一句话成交表达

### 极简版

我们不是卖一个 CRM，而是帮你把客户增长这条线跑清楚。

### 正式版

我们做的是一套围绕企业微信的业务增长中台，帮企业把客户来源、客户分类、销售跟进和老板复盘这条线系统化。

### 老板口语版

客户来了别再散在销售个人微信里，我们帮你把客户怎么来、谁在跟、跟到哪一步这件事看明白。

## 7. 适合老板当面说的收口表达

如果老板问“你们到底是做什么的”，可以直接这样说：

我们不是来替你卖货，也不是来替你接管公司。

我们只做一件事：帮你把客户增长这条线搭起来，让客户进来接得住，销售跟得动，老板看得清。

## 8. 不该说的话

为了避免讲偏，给老板沟通时尽量不要先说这些：

1. 不要先讲系统功能很多；
2. 不要先讲技术架构；
3. 不要先讲 API、自动化、AI；
4. 不要承诺保证成交；
5. 不要把它讲成万能管理系统。

先讲老板现在看不清的问题，再讲系统怎么把这条线跑顺，老板更容易听懂。
