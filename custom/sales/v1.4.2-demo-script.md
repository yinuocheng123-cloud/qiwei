# 5分钟演示脚本

## 1. 开场 30 秒

各位先不要把它理解成普通 CRM，也不要把它理解成一个简单的企业微信工具。

这是一套围绕企业微信的业务增长中台。

它解决的是五件事：

1. 客户从哪里来；
2. 客户属于哪一类；
3. 客户该怎么跟；
4. 销售跟到哪一步；
5. 老板能不能看清楚。

一句话就是：

客户从网上来，企业微信接得住，销售跟得上，老板看得清。

## 2. 第一步：打开 dashboard

### 看什么

1. 客户总量；
2. 来源渠道；
3. 客户类型；
4. 高意向客户；
5. 今日任务；
6. 逾期任务；
7. 销售跟进概览。

### 怎么讲

老板不需要每天追着销售问“客户怎么样了”，因为系统里已经能直接看到：

1. 客户从哪里来；
2. 谁在跟；
3. 跟到哪一步；
4. 哪些客户要优先处理；
5. 哪些销售手里任务已经逾期。

### 一句带过

这一步是先让老板看到结果和过程都不是黑盒。

## 3. 第二步：打开客户列表

### 看什么

1. 16 条整木行业样板客户；
2. 来源覆盖抖音、小红书、视频号、公众号、官网、朋友圈、转介绍、线下活动；
3. 客户类型覆盖业主、经销商、设计师、工厂客户；
4. 每类客户都有不同跟进策略。

### 怎么讲

很多企业的问题不是没人来，而是来了以后都混在一起。

同样是加了企业微信：

1. 业主客户不能和经销商用同一套话术；
2. 设计师不能和工厂老板用同一套资料；
3. 不同客户的成交路径本来就不一样。

### 一句带过

客户能不能分清，是后面能不能跟好的前提。

## 4. 第三步：打开业主客户详情

### 看什么

1. 客户来源；
2. 客户类型；
3. 推荐资料；
4. 推荐话术；
5. 当前任务；
6. 跟进记录。

### 怎么讲

业主关心的是：

1. 效果；
2. 环保；
3. 价格；
4. 交付；
5. 售后。

所以系统推荐的是：

1. 案例图册；
2. 避坑清单；
3. 交付流程；
4. 环保与售后说明；
5. 预约初步方案动作。

### 一句带过

这类客户不是先谈政策，而是先把信任和方案感建立起来。

## 5. 第四步：打开经销商客户详情

### 看什么

1. 招商资料；
2. 合作政策；
3. 到厂考察任务；
4. 跟进节奏。

### 怎么讲

经销商关心的是：

1. 利润；
2. 政策；
3. 区域保护；
4. 总部支持；
5. 样板门店；
6. 风险。

所以不能给他发业主案例，而要发：

1. 招商手册；
2. 产品体系；
3. 合作政策；
4. 到厂考察安排；
5. 招商负责人沟通动作。

### 一句带过

这条路径的重点不是装修效果，而是合作模型能不能成立。

## 6. 第五步：打开设计师客户详情

### 看什么

1. 高定案例；
2. 工艺节点；
3. 材料样册；
4. 项目合作任务。

### 怎么讲

设计师关心的是：

1. 审美；
2. 落地；
3. 工艺；
4. 材料；
5. 项目配合。

所以系统推荐的是：

1. 高定案例图册；
2. 工艺节点说明；
3. 材料样册；
4. 设计师合作机制；
5. 项目合作推进任务。

### 一句带过

设计师要的不是简单报价，而是“你能不能配合我把项目做好”。

## 7. 第六步：打开工厂客户详情

### 看什么

1. 增长诊断表；
2. 企业微信承接自查表；
3. 品牌增信方案；
4. 合作推进任务。

### 怎么讲

工厂老板关心的是：

1. 获客；
2. 招商；
3. 品牌；
4. 成交；
5. 客户承接。

所以这一路径特别适合展示业务增长中台本身的价值。

### 一句带过

这一页不是讲一个客户怎么成交，而是讲企业整条增长线怎么跑顺。

## 8. 第七步：打开销售工作台

### 看什么

1. 今日任务；
2. 逾期任务；
3. 高优先级任务；
4. 本周任务；
5. 已完成任务。

### 怎么讲

销售每天进系统，不是看一堆客户名字，而是看：

1. 今天该跟谁；
2. 哪些客户已经逾期；
3. 哪些客户高意向；
4. 下一句话怎么说；
5. 下一份资料发什么；
6. 下一步动作是什么。

### 一句带过

系统的价值不是替销售干活，而是让销售少漏、少乱、少断。

## 9. 第八步：打开演示说明页

### 看什么

1. 系统演示顺序；
2. 四类客户路径；
3. 老板视角；
4. 销售视角；
5. 产品边界。

### 怎么讲

这个页面是给企业内部统一认知用的。

老板看这里能知道系统值不值得用，销售看这里能知道系统该怎么讲，运营看这里能知道每类客户的内容重点是什么。

### 一句带过

这个页面不是功能页，是企业内部“怎么理解这套系统”的统一入口。

## 10. 结尾 30 秒

最后可以这样收口：

这套系统不是替代销售，也不是接管企业微信。

它做的是把企业客户增长这条线跑清楚：

1. 客户进来有来源；
2. 客户类型能识别；
3. 跟进动作有提醒；
4. 销售过程有记录；
5. 老板能看数据；
6. 后续还能继续运营。

如果企业现在的问题是客户来了接不住、销售跟进不统一、老板看不到过程，那这套业务增长中台就有价值。
